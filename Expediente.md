# Sistema de Ventas para una Tienda de Celulares

## 1. Actor

### Administrador / Vendedor

Es la persona que utiliza el sistema para registrar celulares, consultar el stock y registrar las ventas de la tienda.


## 2. Modulos

### 1. Celulares
Permite registrar y consultar los celulares disponibles en la tienda.

### 2. Inventario
Permite controlar la cantidad de celulares disponibles.

### 3. Ventas
Permite registrar las ventas realizadas.

### 4. Detalle de venta
Permite registrar que celular se vendio, la cantidad y el precio.


## 3. Primeras clases con la receta de 4 pasos

### Paso 1: Sustantivos

Del problema se identifican los siguientes sustantivos:

- Celular
- Venta
- Detalle de venta
- Inventario
- Precio
- Stock

### Paso 2: Verbos

Las acciones del sistema son:

- Registrar celular
- Consultar celular
- Registrar venta
- Agregar celular a una venta
- Calcular total
- Descontar stock
- Consultar stock
